# Оптический стенд для измерения длины ослабления ультрачистой воды (TAIGA)

Программный комплекс на C++ с использованием **CERN ROOT** (и модели в **Geant4**) для прецизионного моделирования прохождения лазерного пучка (405 нм, 5 мВт) через оптическую трубу диаметром 50 мм с окнами из PMMA, заполненную воздухом или ультрачистой водой, для мюонного детектора гамма-обсерватории **TAIGA**.

## 🔬 Физическая модель и решенные проблемы

В старой версии программы наблюдался парадокс: **интенсивность света в воде оказывалась выше, чем в воздухе ($I_{\text{вода}} > I_{\text{возд}}$)**. В новой версии реализованы физически обоснованные исправления:

1. **Френелевское просветление окон PMMA:**  
   Показатели преломления: $n_{\text{air}} = 1.0003$, $n_{\text{pmma}} = 1.4920$, $n_{\text{water}} = 1.3330$.  
   В пустой трубе 4 границы Воздух/PMMA отражают 14.7% света ($T \approx 0.853$).  
   В воде границы PMMA/Вода отражают всего 0.32%, и суммарное пропускание окон составляет $T \approx 0.918$.  
   Вода работает как иммерсионная жидкость, давая **+7.58%** выигрыша по свету, что компенсирует слабое объемное поглощение ультрачистой воды ($\Lambda_{\text{att}} \approx 137\text{ м}$).
2. **Преломление по закону Снеллиуса:**  
   Угол расходимости пучка внутри воды уменьшается в $n = 1.333$ раза ($\theta_{\text{вода}} = \theta_{\text{возд}} / 1.333$). Площадь пятна меньше в $n^2 \approx 1.77$ раза, поэтому пиковая плотность потока в центре выше.
3. **Фокусирующая линза перед лазером:**  
   Сформирован коллимированный пучок с диаметром $D \le 16.2\text{ мм} \le 20\text{ мм}$ на всей дистанции 8 м. Полностью исключены потери на поглощение стенками трубы ($D = 50\text{ мм}$, $R = 25\text{ мм}$).
4. **Матовое стекло (диффузор):**  
   Устраняет пространственную интерференцию и спеклы от лазера 405 нм. Отношение $I_{\text{без диф}} / I_{\text{с диф}} \approx 1.22$ одинаково на всех длинах $L \in \{1, 2, 4, 6, 8\}\text{ м}$.
5. **Выдержки детектора (1.0 мс vs 0.125 мс):**  
   Для мощности 5 мВт выдержка 0.125 мс предотвращает насыщение ячеек CMOS-матрицы при сохранении $\text{SNR} > 38$.

Подробный математический вывод см. в файле [PHYSICS_DESCRIPTION.md](PHYSICS_DESCRIPTION.md).

## ⚙️ Требования и зависимости

- **CERN ROOT**: версия 6.20 или новее (с поддержкой `TMinuit`, `TH1D`, `TH2F`, `TGraph`).
- Компилятор C++ с поддержкой C++14/C++17 (GCC $\ge$ 7 или Clang $\ge$ 6).
- Bash-окружение (Linux / macOS).

## 🚀 Инструкция по запуску

### Быстрый запуск одним скриптом:
```bash
chmod +x run_pipeline.sh
./run_pipeline.sh
```

### Пошаговый запуск через CERN ROOT:
1. **Генерация Монте-Карло данных:**
   ```bash
   root -l -b -q "water_sim_v2.C+"
   ```
   Этот шаг моделирует прохождение миллионов фотонов для длин 1, 2, 4, 6, 8 м в воздухе, воде, с матовым стеклом и при выдержках 1 мс и 0.125 мс.

2. **Реконструкция и сохранение графиков:**
   ```bash
   root -l -b -q "analyze_data_v2.C+"
   ```
   Скрипт автоматически создаст каталог `result/` и сгенерирует все требуемые изображения высокой четкости (PNG).
