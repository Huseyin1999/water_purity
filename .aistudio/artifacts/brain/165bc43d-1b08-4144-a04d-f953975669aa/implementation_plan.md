# План: Функция скачивания ZIP-архива репозитория и инструкция переноса на GitHub

### Причина ситуации
AI Studio Build работает в изолированном облачном контейнере. Созданные файлы (`README.md`, `PHYSICS_DESCRIPTION.md`, `water_sim_v2.C`, `analyze_data_v2.C`, `run_pipeline.sh`) находятся в файловой системе контейнера приложения и не могут автоматически отправиться на внешний GitHub (`https://github.com/Huseyin1999/water_purity`), поскольку у среды нет вашего личного GitHub токена/SSH ключа.

---

### Подтвержденное решение пользователя
- **Способ переноса**: Скачивание единого готового ZIP-архива из веб-приложения в один клик с последующим коммитом в репозиторий.
- **Интерфейс**: Добавление кнопки «Скачать архив репозитория (ZIP)» в шапку и разделы приложения.

---

### 2. План выполнения

#### Шаг 1: Установка пакета `jszip`
- Установить `jszip` и `@types/jszip` для быстрой и надежной упаковки всех файлов прямо в браузере.

#### Шаг 2: Создание утилиты сборки архива (`src/utils/zipExport.ts`)
- Формирование полного архива `water_purity_files.zip` со всеми файлами:
  1. `README.md` (руководство по репозиторию)
  2. `PHYSICS_DESCRIPTION.md` (полный физико-математический разбор)
  3. `water_sim_v2.C` (исправленная Монте-Карло симуляция)
  4. `analyze_data_v2.C` (скрипт сохранения всех графиков в `result/`)
  5. `run_pipeline.sh` (скрипт автозапуска)
  6. Исходные файлы Geant4 модели (`DetectorConstruction.cc`, `PrimaryGeneratorAction.cc`, `PhysicsList.cc`, `run_taiga.mac`, `CMakeLists.txt`).

#### Шаг 3: Обновление интерфейса
- Добавление заметной кнопки **«📦 Скачать архив для GitHub (ZIP)»** в шапку сайта и во вкладку **«Каталог графиков (result/)»**.
- Добавление диалогового окна с пошаговой инструкцией (3 простые команды: разархивировать, `git add .`, `git commit -m "..."`, `git push`).
- Предоставление альтернативного способа через веб-интерфейс GitHub (кнопка `Add file -> Upload files` на странице репозитория `https://github.com/Huseyin1999/water_purity`).

#### Шаг 4: Проверка сборки и тестов
- Компиляция приложения (`compile_applet`) и проверка линтера (`lint_applet`).
